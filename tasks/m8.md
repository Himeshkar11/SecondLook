## 4. BID OWNERSHIP

==================================================

This is critical.

A bidder may create/access/manage ONLY their own bids.

The backend must derive the bidder from the authenticated user.

Do NOT trust:

```

```

from the request body as proof of ownership.

The secure relationship must be:

```
authenticated user
      ↓
bidder profile/entity
      ↓
bid
      ↓
tender
```

Test:

```
Bidder A → own bid → ALLOWED

Bidder A → Bidder B bid → DENIED
```

Changing:

```
bid_id
bidder_id
user_id
```

must not bypass ownership.
